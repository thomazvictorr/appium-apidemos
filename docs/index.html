// ci/cd

Pipeline GitHub Actions

1
Checkout do repositório actions/checkout@v4.2.2
2
Configurar Java 17 actions/setup-java@v4 — Temurin distribution
3
Compilar projeto mvn compile -q
4
Validar dependências mvn validate -q
5
Compilar testes mvn test-compile -DskipTests=true -q
6
Execução dos testes requer emulador Android — rodar localmente com mvn test
